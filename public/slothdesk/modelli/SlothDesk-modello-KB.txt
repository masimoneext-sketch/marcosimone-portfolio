# Reset della password di un utente
Categoria: Account
Livello: 1
Domanda: come si reimposta la password di un utente?

Prima di tutto verifica l'identità dell'utente, poi apri **Utenti e computer di Active Directory**.

1. Cerca l'utente per nome o per account.
2. Tasto destro sull'utente → «Reimposta password».
3. Spunta «L'utente deve cambiare la password all'accesso successivo».
4. Comunica la password temporanea all'utente a voce, mai per email.

## Se l'account è bloccato

Nella scheda «Account» togli la spunta «Sblocca account», poi reimposta la password.

Categoria: Stampanti
Livello: 1
